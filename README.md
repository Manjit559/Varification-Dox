🚀 Overview

Verification-Dox is an AI-powered web application that securely verifies user identity by analysing user-uploaded identity documents (Aadhaar, PAN, Passport, Driving Licence, etc.) and matching them with a live selfie. It uses OCR, Computer Vision, and AI to automate document verification while ensuring privacy and security.


✨ Features
🔐 Secure Login & JWT Authentication
📄 Upload Identity Documents
🤖 AI OCR for Data Extraction
😊 Face Detection & Face Matching
🛡️ Liveness Detection
📊 Verification Dashboard
📑 Download Verification Reports
☁️ Secure Cloud Storage
👨‍💼 Admin Dashboard & Analytics
🛠️ Tech Stack


Frontend: React.js, Next.js, Tailwind CSS
Backend: Java, Spring Boot, REST API
AI: Python, OpenCV, EasyOCR, Tesseract OCR, MediaPipe, Google Gemini API
Database: PostgreSQL, MongoDB
Cloud & Tools: AWS EC2, AWS S3, Git, GitHub, Maven, Postman, Docker


🔄 Workflow
📤 Upload Document → 🤳 Upload Selfie → 🤖 OCR Extraction → 😊 Face Detection → 🔍 Face Matching → 📑 Verification Report → 📊 Dashboard


🔒 Security
🔑 JWT Authentication
🔐 Encrypted Data Storage
🛡️ Role-Based Access Control
📋 Audit Logs
🌐 HTTPS Support
📌 Note

This project is intended only for identity verification with the user's knowledge and consent. It does not identify unknown individuals or retrieve personal information from photographs.
